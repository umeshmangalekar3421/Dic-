# ML-Assisted PVT-Robust Standard-Cell Optimization

**Digital IC Design course project** · SKY130-calibrated · fully open source · laptop-scale

A standard cell that is correct in a schematic can still fail after fabrication:
threshold voltage, channel length and mobility all wander (process corners +
Pelgrom mismatch), and so do supply and temperature.  This repository is a
complete flow that

1. characterizes a mini 1.8 V cell library (INV, NAND2, NOR2, AOI21, OAI21, MUX2, XOR2, DFF),
2. trains a machine-learning surrogate of delay / energy / leakage,
3. sizes transistors with yield-aware NSGA-II,
4. writes an NLDM Liberty file,
5. times a registered 8-bit ripple-carry adder,
6. emits a report and a slide deck.

**You do not need the SkyWater PDK, Magic, KLayout, ngspice, Yosys or OpenROAD.**
Those tools were deliberately dropped — they blow a 100 GB disk budget and they
are not what this course grades.  Optional ngspice netlists still live in
`spice/` if you install ngspice later.

The only runtime is Python 3.10+ with NumPy, SciPy, scikit-learn and Matplotlib.

## Run it (Windows — IdeaPad Slim 3i)

In PowerShell, from this folder:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -U pip
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run_project.py
```

Or double-click `run.bat`.

Then open:

- `docs/REPORT.html` — the full report (File → Print → Save as PDF for submission)
- `docs/SLIDES.html` — arrow keys to present
- `results/metrics.json` — every number in the report
- `results/liberty/*.lib` — NLDM libraries
- `results/figures/` — all plots

`--quick` shrinks the DOE and NSGA-II for a 2–3 minute demo:

```powershell
.venv\Scripts\python run_project.py --quick
```

## Why this idea, and what was changed

**Problem.**  One chip is faster than another; leakage varies; some dice miss
timing; yield drops.  The bicycle analogy in the brief still holds: design so
that almost every manufactured copy works.

**Dataset.**  There is no public SKY130 dataset of *(W<sub>n</sub>, W<sub>p</sub>, V, T, corner, load) → (delay, leak, energy)*
at the resolution an optimizer needs.  Foundry `.lib` files give *fixed* drive
strengths.  The dataset is therefore generated by a Latin-hypercube design of
experiments on a compact MOSFET model **pinned to published SKY130 Ion / Ioff / FO4**.
That is the academically correct substitute for Liberate + BSIM when you have
no NDA.

**Cuts.**  Full PDK + OpenROAD RTL-to-GDS was removed.  See `docs/ROADMAP.md`.
On a Slim 3i with 100 GB free that stack is the most likely way to fail the
course.  The ML, the PVT physics, the Liberty and the STA stay.

## Method in one paragraph

Sakurai α-power law plus subthreshold leakage, temperature (`μ ∝ T⁻¹·⁵`,
`dV<sub>t</sub>/dT ≈ −1.6 mV/K`), ss/tt/ff corners and Pelgrom `σVt = AVt/√(WL)`.
Delay is `0.69 C_eff V / I_drive` with stack derating.  HistGB replaces the
characterizer inside NSGA-II (three objectives: worst-corner delay, typical
energy, 1−yield).  Knee points are re-simulated (physics + 220-shot MC) and
written as Liberty.  The adder is timed by bilinear interpolation of those
tables.

References are listed at the end of `docs/REPORT.html` (Sakurai 1990,
Pelgrom 1989, Deb NSGA-II 2002, Rabaey, Weste/Harris, Logical Effort, SKY130 PDK).
