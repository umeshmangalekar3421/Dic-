Roles this product prepares you to talk to

Two-minute demo script (read this before an interview)

  1. Live lab. Open NAND2, drop VDD from 1.8 to 1.5 V, switch tt → ss. Delay should jump. That is PVT. Recruiters want to see you drive a cell, not recite a slide.
  2. Devices. Show the subthreshold plot. “Leakage doubles every ~9 °C; ff/hot is a power problem, ss/cold is a timing problem.”
  3. Library. Min-size INV fails the delay spec (yield 0). ML-opt passes. Balanced logical-effort is already good — ML is the last 10–20 %, which is how real library teams talk.
  4. Models. HistGB R² 0.96 vs Ridge 0.68. “We do not skip physics. The surrogate sits inside NSGA-II; the knee is re-simulated.”
  5. STA. 8-bit RCA, 614 MHz tt / 426 MHz ss, 96 % yield at 400 MHz. “Ripple carry is the slow topology on purpose — I can discuss CLA next.”
  6. Limits. Say them yourself: compact MOS not BSIM, no SPEF, ideal clock. Honesty is a hiring signal.
